# SSS

Here lies the code that gives birth to the website which hosts my Short Story Saturdays (SSSs)

## Layout

```
build/          config, util (text/dates/slugs), markdown, stories, pages
icons/logo.svg  site logo
css/
js/             main.js (entry, keys) and sidebar.js
src/			where the raw text is pasted
templates/      page shell
build.js        build websites from the raw text
```

Settings live in `./build/config.js`.
